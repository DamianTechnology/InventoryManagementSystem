# Inventory Management System API

A backend project built to practice CRUD operations with Node.js and MongoDB.

This API allows users to manage an inventory of products. Each product has a name, price, and quantity.

**Key Learning Outcomes:**
1.  Setting up an Express server
2.  Connecting Node.js to MongoDB using Mongoose
3.  Building RESTful routes with MVC structure
4.  Handling errors and environment variables

**Endpoints:**
`POST /api/products` - Create product
`GET /api/products` - Get all products
`GET /api/products/:id` - Get single product
`PUT /api/products/:id` - Update product
`DELETE /api/products/:id` - Delete product
